## APIs

- [Content API (WordPress REST)](https://www.ascend-adv.com/wp-json/): The site's WordPress REST API, base URL https://www.ascend-adv.com/wp-json. Anonymously readable. Exposes News & Insights posts, site pages, media, categories and tags, site search, content-type and taxonomy metadata, and the `awsm_job_openings` custom post type behind the Careers listings. Writes require WordPress Application Password credentials over HTTP Basic. This is a marketing-site content API, not a product API offered to Ascend customers.

Key endpoints:

- `GET /wp-json/wp/v2/posts` — News & Insights posts (55 at time of capture). Supports `page`, `per_page` (1-100), `search`, `categories`, `tags`, `slug`, `order`, `orderby`.
- `GET /wp-json/wp/v2/pages` — static site pages.
- `GET /wp-json/wp/v2/awsm_job_openings` — open roles.
- `GET /wp-json/wp/v2/categories` — news, articles, blogs, webinar.
- `GET /wp-json/wp/v2/media` — media library, including posters and white papers.
- `GET /wp-json/wp/v2/search?search=<term>` — cross-content search.
- `GET /wp-json/wp/v2/types` — registered content types and their REST bases.

Conventions: page-number pagination via `page` and `per_page`, with totals in the `X-WP-Total` and `X-WP-TotalPages` response headers and an RFC 8288 `Link` header carrying `rel="next"`. Pass `_embed` to inline related author, media, and term resources. Errors are the WordPress REST envelope (`code`, `message`, `data.status`) as `application/json` — not RFC 9457 problem+json. No idempotency contract, no documented rate limits, no request-id header.
